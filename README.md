# Meeting Canvas

Zoom / Google Meet の録画・録音から、文字起こし、議事録、1枚図解を作る無料のブラウザアプリです。

## 特徴

- 音声処理はブラウザ内。録画を独自サーバーへアップロードしません
- MP3 / M4A / WAV とブラウザが再生できる動画に対応
- 日本語Whisperで文字起こし
- 要約・決定事項・アクションを自動整理
- Markdown議事録とPNG図解を保存
- スマートフォン対応、APIキー不要

## 使い方

1. ZoomまたはGoogle Meetで、参加者の同意を得て録画します。
2. 録画・録音ファイルをMeeting Canvasに入れます。
3. 完成した議事録と図解を確認し、保存します。

初回は文字起こしモデルをダウンロードします。端末性能や録画時間によって処理時間が変わります。長時間会議は音声だけにして分割すると安定します。

## 開発

```bash
npm run dev
npm test
```

## GitHub Pages

リポジトリの `Settings > Pages > Source` を `GitHub Actions` にすると、mainへのpushで公開されます。

## プライバシー

録画・録音前に参加者へ目的を説明し、同意を得てください。生成結果は必ず人が確認してください。公開リポジトリへ会議データをコミットしないでください。

## 無料版の制限

- Botが会議へ自動参加する機能はありません
- 録画開始とファイル選択は主催者が行います
- 話者分離は未対応です
- 要約は端末内のルールベース処理です
